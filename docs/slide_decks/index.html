PILOT with Devin

Power Apps carries governance, audit, DLP, and managed operations. Custom build gives control and lower licensing dependence, but the team inherits security, reliability, and operating ownership.

boundary // what transfers, what does not

Custom code can reproduce the workflow. Platform guarantees require deliberate replacement.

Replicable with Devin-assisted engineering

  • Custom workflow UI and server-side role checks
  • Approval rules and state machines
  • Audit capture
  • Provider adapters and automated tests

Still requiring production work

  • Real provider integration, idempotency, reconciliation
  • SSO, MFA, onboarding and offboarding
  • DLP and durable audit controls
  • Monitoring, backups, on-call ownership

closing ask // decision, not leap

Start with a bounded pilot, then let evidence decide whether to expand, retain, or run hybrid.

90-day sequence

  • 0 to 30: validate tenant economics and security requirements
  • 31 to 60: run one bounded workflow with a real internal team
  • 61 to 90: measure cycle time, recovery, audit completeness, engineering effort

Three outcomes at day 90

  • Expand the custom-build path
  • Retain Power Apps
  • Hybrid: Power Apps for governed workflows, custom for bounded tools
